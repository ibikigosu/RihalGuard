# Risk levels

- **RG-0 - Passive:** Reads provided input only. No external tools.
- **RG-1 - Lookup:** Can retrieve from approved sources. No state changes.
- **RG-2 - Structured Output:** Can extract, summarize, classify, draft, or recommend. No side effects.
- **RG-3 - Review-Gated:** Can prepare actions or payloads, but human approval is required before mutation.
- **RG-4 - Controlled Execution:** Can execute limited reversible actions inside a defined scope.
- **RG-5 - Autonomous Workflow:** Can execute consequential actions without complete approval, reversibility, or execution bounds.
