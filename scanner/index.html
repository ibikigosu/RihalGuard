What it scores

          
The scanner maps input to RihalGuard design controls: contract completeness, scope, tool policy, data handling, output integrity, runtime limits, human review, audit, verification, and ownership.

        

        

          
What it cannot prove

          
A browser scan cannot prove tool metadata, identity, runtime enforcement, access control, production logging, or downstream approval workflows. Contract-only risk inference is marked partial until the reviewed tool manifest is validated with the repository. Treat this as a design-layer screen before deeper review.

        

        

          
Why deterministic

          
Governance checks should be reproducible. The same input gets the same gate results, and employees can paste the fix block straight into a contract or prompt review.
